🔍 Troubleshooting

If it's not working:

  1. Open Chrome DevTools (F12) and check the Console tab
  2. Look for [Secure Paste Guard] Extension initialized
  3. Go to chrome://extensions/ and reload the extension
  4. Make sure the extension is enabled
  5. Try refreshing this page (F5)
